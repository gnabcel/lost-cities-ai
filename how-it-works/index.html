Lost Cities AI · how it works

Inside the Lost Cities Bot

A 3 MB neural network learned the card game Lost Cities by playing against itself on one gaming PC. It now beats its author three matches out of four. This page walks through how it plays, how it learned, and what it took to get there.

01

Half the cards are hidden

Lost Cities has 60 cards in five colours, one per expedition. Each colour has cards 2 to 10 and three wager cards. On your turn you play a card onto one of your expeditions or discard it, then draw from the deck or from the top of a discard pile. Expeditions must go up in value, every expedition you start costs 20 points, and wagers multiply the result.

You never see your opponent's eight cards or the order of the deck. That rules out the chess approach of searching the game tree directly, because the bot doesn't know which tree it is in.

02

A small network makes the first guess

The position is turned into 429 numbers: which cards sit where, plus a few per-colour summaries such as how many useful cards are still out there. A plain neural network (three layers of 512 units) turns those numbers into two answers.

The policy scores all 126 moves. Illegal moves are masked out and the rest become probabilities. The value estimates how many points ahead or behind the bot will finish the round. Picking the most likely move already plays well. It takes about a millisecond.

03

Four stages of learning

The network started knowing nothing. Each stage built on the previous one, and each was measured in points per round against a hand-written rule-based bot.

04

The teacher imagines 64 deals

To beat the network you need something that plays better than it. That teacher is a search built on top of the network itself. On each move it takes the network's top four candidates and deals the 38 unseen cards at random, 64 times, consistent with everything the bot has seen. In each imagined deal it plays the candidate and lets the network finish the round for both players.

Each candidate gets the average result over the same 64 deals, plus a bonus for the network's own confidence: score = mean + 2 · ln(probability). The bonus stops the search from overruling the network on noise alone. The technique is called determinized Monte Carlo search, or PIMC.

05

The loop: play, learn, test

Expert iteration repeats three steps. The current champion plays a thousand rounds against itself with the search on every move. A fresh network is trained from scratch to predict what the search chose, using the last twelve iterations of games. The new network then plays the champion, and only takes over if it wins clearly.

A better network makes the simulations inside the search more realistic, which makes a better teacher, which trains a better network. That is the same idea as AlphaZero, adapted to hidden cards.

06

Did it work?

Lost Cities is luck-heavy, so the test is head-to-head over many rounds, alternating who sits where and who starts. Every network below played 16,000 rounds against the iteration-4 network. The champion at iteration 44 finishes 11.5 points ahead per round, winning 60% of rounds. Over a three-round match that edge adds up.

07

What unblocked it

Training stalled four times. Each fix came from measuring the problem first, usually by pitting two versions against each other.

08

Under the hood

Everything is plain Python on top of PyTorch. There is no reinforcement-learning framework: PPO, the search and the expert-iteration loop are about a thousand lines written for this game.

PieceUsed for
PyTorchThe network, backpropagation (autograd), the Adam optimiser, learning-rate schedules, CUDA on the GPU, and the ONNX export
NumPyBuilding the 429-number inputs in batches, storing each iteration's training data
multiprocessingRunning the self-play search on 7 CPU cores at once, the slowest part of every iteration
ONNX Runtime WebRunning the network in the browser; the game engine was ported to JavaScript and checked move for move against Python
Chart.js · pytestThe training dashboard; tests for the rules and the network inputs
HardwareOne gaming PC: an 8-core CPU and an RTX 3070 with 8 GB
